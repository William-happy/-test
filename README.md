## 冒泡排序 (Bubble Sort)

本项目包含了冒泡排序算法的Python实现。

### 文件说明

- `bubble_sort.py`: 冒泡排序的实现和演示代码
- `test_bubble_sort.py`: 单元测试

### 使用方法

运行演示程序：
```bash
python3 bubble_sort.py
```

运行测试：
```bash
python3 -m unittest test_bubble_sort.py -v
```

### 算法说明

冒泡排序是一种简单的排序算法，通过重复遍历列表，比较相邻元素并交换顺序错误的元素。

- **时间复杂度**: O(n²)
- **空间复杂度**: O(1)
- **稳定性**: 稳定排序
